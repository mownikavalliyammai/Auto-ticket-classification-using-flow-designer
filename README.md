# Auto Ticket Classification Using Flow Designer

## Project Overview

Auto Ticket Classification is a ServiceNow project developed using Flow Designer to automate the classification of IT service tickets.

The system processes ticket information and automatically identifies the appropriate category, priority, and assignment group based on the configured automation logic.

## Objectives

- Automate IT ticket classification
- Reduce manual effort
- Improve ticket management
- Automatically assign appropriate categories and priorities
- Improve the efficiency of incident management

## Technologies Used

- ServiceNow
- Flow Designer
- ServiceNow Personal Developer Instance (PDI)
- GitHub

## Main Features

- Automatic ticket processing
- Ticket classification
- Automated workflow execution
- Category and priority assignment
- Assignment group routing
- Reduced manual intervention

## Workflow

1. A ticket is created or received.
2. The Flow Designer flow is triggered.
3. Ticket information is processed.
4. The ticket is classified based on the configured logic.
5. Appropriate category, priority, and assignment information is determined.
6. The ticket is updated automatically.

The repository contains the exported ServiceNow Update Set in XML format.
